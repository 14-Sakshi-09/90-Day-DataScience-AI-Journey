# ✅ 1. DSA — Climbing Stairs (LeetCode #70)

Solved the problem using an optimized Dynamic Programming approach based on the Fibonacci pattern.

### What I Learned
- Recognized the **Fibonacci-style recurrence**: `dp[i] = dp[i-1] + dp[i-2]`
- Used previously calculated results to avoid repeated work
- Optimized the solution from an array-based DP to **O(1) extra space**
- Practiced handling small edge cases separately

**Key Takeaway:**  
Many staircase/counting problems can be recognized as Dynamic Programming when the current answer depends on the previous two states.

**Complexity:** O(n) time, O(1) extra space
