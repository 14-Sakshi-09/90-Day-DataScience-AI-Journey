# ✅ 1. DSA — Two Sum II: Input Array Is Sorted

**Problem:** LeetCode #167 — Two Sum II: Input Array Is Sorted
**Difficulty:** Medium
**Language:** C++

### 🧠 Approach

Used the **Two Pointer technique** on the sorted array:

* Started one pointer from the beginning and another from the end
* Compared their sum with the target
* If the sum was smaller than the target, moved the left pointer forward
* If the sum was greater than the target, moved the right pointer backward
* Returned the required 1-indexed positions when the target was found

### ⏱️ Complexity

* **Time Complexity:** `O(n)`
* **Space Complexity:** `O(1)`

### ⭐ Key Milestone

This was my **first DSA problem solved in C++ as part of my new strategy**.

More importantly, I solved it **independently without AI assistance**. Instead of looking up the solution, I recognized the Two Pointer pattern and applied it myself.

That felt like a genuine sign that the pattern is starting to click.

**Result:** ✅ Solved
