**Weak Topics & Quick Notes**

| Topic | One-Line Explanation | Example |
|-------|----------------------|---------|
| `is` vs `==` | `==` compares values, while `is` checks whether two variables refer to the same object in memory. | `[1,2] == [1,2]` → `True`, `[1,2] is [1,2]` → `False` |
| `self` | `self` refers to the current object, allowing access to its attributes and methods. | `self.name = "Sakshi"` |
| `super()` | `super()` calls methods or constructors of the parent class. | `super().__init__()` |
| `for-else` | The `else` block executes only if the loop finishes normally (without `break`). | `for i in range(3): print(i) else: print("Done")` |
| `if __name__ == "__main__"` | Ensures code runs only when the file is executed directly, not when imported. | `if __name__ == "__main__": main()` |
